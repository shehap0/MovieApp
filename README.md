# MoveApp

## 📱 Project Overview

MoveApp is an Android application developed as a team project. The app focuses on providing a clean, user-friendly mobile experience while applying core Android development concepts using Android Studio.

This project was built collaboratively as part of academic and practical learning objectives.

---

## 🛠️ Technologies Used

* Android Studio
* Java
* XML (UI Design)
* Gradle

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone (https://github.com/shehap0/MovieApp)
   ```
2. Open **Android Studio**
3. Click **Open** and select the project folder
4. Wait for **Gradle Sync** to complete
5. Run the app on an emulator or physical device

---

## 📌 Notes

* Make sure the correct Android SDK version is installed
* Internet connection may be required for Gradle dependencies
